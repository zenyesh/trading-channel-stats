Privacy Policy: Trading Channel Stats

Last updated: 7 November 2026

Who uses it. Only the owner of one YouTube channel, for their own channel. It is not offered to the public.

What it accesses. With the owner's consent, read-only YouTube data for the owner's own channel through the YouTube Data API and YouTube Analytics API: channel and video statistics such as views, likes, comments, watch time, average view duration, subscribers gained and traffic sources.

How it is used. Only to build a private daily summary that is sent to the owner. The data is not sold, shared with third parties, used for advertising, or used to train models.

Storage. The OAuth refresh token is stored as an encrypted secret in the owner's private automation account. Statistics are not stored beyond the daily message.

Google API Services. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access. Access can be removed at any time at myaccount.google.com/permissions.
